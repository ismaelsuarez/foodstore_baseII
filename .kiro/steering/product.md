# Food Store

A relational database project for a food store (UTN – Base de Datos II). It models the core commerce flow: product catalog organized by categories, customer management, and order processing with itemized order details.

The database tracks:
- **Categorías** – product groupings (e.g., Pizzas, Bebidas)
- **Productos** – items for sale with price, stock, and category
- **Clientes** – customers identified by email
- **Pedidos** – orders linked to a customer with a payment method
- **Detalle de pedido** – line items that make up each order (quantity + unit price at time of sale)

This is an academic/educational project. SQL files are written in Spanish following local naming conventions.
